# Coral · Tenor

App de treino vocal para coralistas: afinador ao vivo, aquecimento, teste de alcance, correção de afinação e ritmo, diário.

As músicas (letra, notas e áudios) **não ficam neste repositório**: cada pessoa importa o próprio arquivo de música, que fica guardado só no aparelho.

App: https://eumagnotavares-jpg.github.io/Coral/
